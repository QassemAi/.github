# QassemAi

QassemAi hosts engineering projects in packaging, infrastructure, defensive security and applied data analysis. The projects below have inspectable source and local verification instructions.

| Project | What you can verify | Current scope |
| --- | --- | --- |
| [QassemRPM](https://github.com/QassemAi/QassemRPM) | RPM spec metadata, Markdown output, validation and a local build wrapper | Packaging CLI with unit tests and a container definition |
| [Qassem DevSecOps Lab](https://github.com/QassemAi/Qassem-DevSecOps-Lab) | Python checks for common secret, Docker and IaC patterns | Defensive lab with heuristic checks |
| [Qassem Sales Analytics](https://github.com/QassemAi/Qassem-Sales-Analytics) | Sales summaries, KPIs, reports and moving-average forecasts | Analytics example with local tests and sample data |
| [Qassem Kubernetes PlatformOps](https://github.com/QassemAi/Qassem-Kubernetes-PlatformOps) | GitOps, observability, policy and infrastructure examples | Lab templates with a small CLI parser test |
| [Qassem DRBD Tools](https://github.com/QassemAi/Qassem-Drbdtools) | Validated construction of DRBD administration commands | Storage utility with unit tests and dry-run options |
| [SpaceX Falcon 9 Landing Prediction](https://github.com/Kasem-Adra/SpaceX-Falcon9-Landing-Prediction) | Notebooks for collection, SQL analysis, visualization and classification | Coursework in the maintainer’s personal account |

Maintenance varies by project. The linked repositories show their current history, build instructions and test scope.
